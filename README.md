# Demo-Trading-and-Limit-order-Book

`Demo Trading Message Data and Limit Order Book.ipynb` — an executed
analysis notebook (41 cells, all outputs saved, no errors) that works with
limit-order-book message data: reconstructing and examining the order book
from exchange message traffic.

## Data — synthetic LOBSTER-format sample (new Nov 2026)

The notebook reads two files from `classdata/`:

- `classdata/message.csv` — exchange message traffic
- `classdata/orderbook.csv` — order-book snapshots

The originals are licensed LOBSTER/course data and are not
redistributable. The copies now bundled in `classdata/` are **synthetic
sample data in LOBSTER format**, generated by
`make_synthetic_classdata.py` (a small simulated order book: 1,161
message events over one trading day, with a matching 40-column
order-book snapshot after every event). They preserve the format and
the relationships the notebook checks — fully cancelled orders have
type-1 size = type-3 size, fully executed orders have type-1 size =
type-4 size, hidden executions carry OrderID 0 — but they are **not
real market data**, and any statistics computed from them are
illustrative only.

## Run status (verified Nov 2026)

The notebook was re-executed top-to-bottom against the bundled
synthetic data with **zero errors**; the outputs saved in the notebook
are from that run. To reproduce:

```bash
pip install -r requirements.txt
python make_synthetic_classdata.py   # regenerates classdata/ (optional)
jupyter nbconvert --to notebook --execute --inplace \
    "Demo Trading Message Data and Limit Order Book.ipynb"
```

(If you have the licensed course files, dropping them into `classdata/`
in place of the synthetic ones is all it takes to run the notebook on
real data instead.)
